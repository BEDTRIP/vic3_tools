# After stage 2: the six reference tasks with the index (2026-10-15)

The tasks and their reference answers are in [`2026-10-15-baseline.md`](2026-10-15-baseline.md). Same setup: a fresh
Claude Sonnet subagent, read-only, the fork at `master`, game 1.13.11; the index (`v3 def` / `refs` / `loc` /
`outline` / `winner`) built for the playset "Ledgerdemain" with the fork mapped to its git checkout.

## Why a new "before"

A fresh agent now starts at **50.3 k tokens** (measured: an agent told to answer "OK" with no tools), against ~37.5 k
in the morning — the session around it has more skills and longer `CLAUDE.md` files. The morning numbers are therefore
not comparable as they are. All three arms below ran in the same sitting, and the table gives **tokens over that start**.

Three arms:

- **before** — "do not use `v3`" (grep and reading, as in the morning); one run per task;
- **rule only** — the new section of `vic3_mods/CLAUDE.md` ("search with `v3` first") quoted in the prompt, as a fresh
  session would see it; two runs per task;
- **v3 told** — "use `v3` first, fall back to grep only for what it cannot answer"; one run per task.

## What this says

- **When the agent uses the index, the six tasks cost about half** (103 k → 55 k over the start). The big ones gain the
  most: T3 (following a chain of script values up to an on_action, finding who writes) −58 % and 18 → 7 calls; T5
  (a GUI template chain) −59 %. On T1 and T6 grep was already cheap — small gains only.
- **The rule in `CLAUDE.md` is not enough to make agents use it.** With the rule only, `v3` was used in T4 (both runs)
  and T5 A; the rest went to grep as before, and T3 B missed half the answer for it. A line in a long `CLAUDE.md` loses
  to habit. Next: make it hard to miss — a short skill that triggers on "where is X defined / who uses X / which wins",
  and the hook of stage 4 answering a grep over game or mod folders with a pointer to `v3 refs` / `v3 def`.
- The fixed start (50 k) dwarfs the work on easy tasks. Trimming what a fresh agent loads (skills listed, `CLAUDE.md`
  length) saves more on T1/T6-like questions than any tool.
- One or two runs per arm — the spread between runs of the same arm (T3 rule only: 24 k vs 36 k) is as large as some
  differences. Read the totals, not single cells.
